# Saketh Vadlamudi — Portfolio

A responsive single-page portfolio focused on enterprise AI, Oracle data systems, decision platforms, and selected open-source work.

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

The site uses plain HTML, CSS, and JavaScript with Bootstrap and Font Awesome loaded from CDNs. Résumé versions are intentionally retained under `Images/Resume/`.
